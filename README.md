# 🎓 Student Dropout Dashboard

## 👋 Welcome!
This is an easy-to-use web dashboard that helps schools figure out **why students drop out**. 

Instead of staring at a giant, boring spreadsheet with 100,000 rows, this tool turns all that data into beautiful, interactive charts so anyone can understand it.

## 🌟 What Can It Do?
* **Quick Filters:** Want to only see STEM students? Or international students? Just click a box to filter the data instantly.
* **Find the "Why":** It automatically calculates exactly what causes students to leave (like long commutes, high stress, or missed classes).
* **Interactive Charts:** It features fun, clickable circle charts and color-coded maps to make the numbers easy to read.
* **Solutions:** It gives a real action plan on how to help at-risk students before it's too late.

## 💻 Built With
* **Python** (The programming language)
* **Streamlit** (To build the web page)
* **Pandas & Plotly** (To do the math and draw the charts)

## 🛠️ How to Run It on Your Computer
1. Download these files to your computer.
2. Open your terminal or Anaconda Prompt.
3. Install the required tools by typing:
   `pip install -r requirements.txt`
4. Start the dashboard by typing:
   `streamlit run dashboard.py`
